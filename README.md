# 🔗 سرویس کوتاه کننده لینک (URL Shortener API)

---

## ویژگی‌های اصلی

1-امکان تعیین نام دلخواه برای لینک کوتاه شده 
2-تولید خودکار لینک در صورت انتخاب نکردن نام دلخواه
3-شمارش تعداد کلیک ها برای هر لینک 
4-انقضای لینک پس از 24 ساعت بر اساس زمان ثبت لینک
5-احراز هویت و ورود کاربران با استفاده از توکن 
---

## تکنولوژی‌های استفاده شده

- **Framework:** FastAPI
- **Database:** PostgreSQL
- **Data Validation:** Pydantic (v2)
- **Server:** Uvicorn

--
## اندیپونت ها 
1- (/register)	        ثبت‌نام کاربر جدید
2-(/login)              JWTورود و دریافت توکن
3- (/shorten)	        ساخت لینک کوتاه (با قابلیت شخصی‌سازی)
4- (/{short_code})	ریدایرکت به لینک اصلی (به همراه شمارش کلیک)
5- (/stats/{short_code})	دریافت آمار کلیک‌ها

--
## مراحل اجرای پروژه :

1- دانلود کنید github تمامی فایل های پروژه را از طریق لینک
